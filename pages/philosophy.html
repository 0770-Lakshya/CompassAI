We’re at our best when we’re making.

A few beliefs that shape how we build at OpenLake.

01

Coding is a superpower.

Learning to code converts you from a consumer to a creator. Suddenly, computers become a tool for making things instead of just using them.

02

Build from anywhere.

Anyone with a laptop and an internet connection can learn to build software. Making things has never been this democratized.

03

Hack, hack, hack.

We want a space on campus where people are making interesting things with code, every week. Most places don't provide that, so we built it.

04

Start building.

Most courses teach concepts instead of how to write real code — like learning carpentry without any wood. Here you learn entirely through shipping.

05

Learn as you build.

Starting out, you won't understand how all the code works. You'll build that understanding as you go, and you'll get stuck along the way. We're here for that part.

Browse our projects →
06

Be part of a community.

OpenLake gives you a room full of other people building things. We're designers, writers, engineers, tinkerers. We help one another. Join us.
